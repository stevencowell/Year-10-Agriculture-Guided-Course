# Plans and drawings authority

## Confirmed 2026 position

The exhaustive `Year 10/2026` Drive audit found no supplied dimensioned project plan, farm layout, paddock plan, yard plan, plant-trial layout or finished pedigree drawing. No generic substitute may be presented as a Wagga Wagga High School requirement.

The formal Task 3 source does, however, create one authoritative student drawing requirement:

- `2026 Assessment Task 3 - Prime Lamb Production Report.docx`, Drive ID `1rh8Tedl_c2XQ3-aw0KqpOBCWfmmqef-w`, requires students to develop a prime-lamb breeding program and draw a pedigree.
- The source describes the structure as a Merino ewe crossed with a variable ram to produce a first-cross ewe, followed by the first-cross ewe crossed with a selected terminal sire to produce prime lambs.
- The student must select and justify the variable ram and terminal-sire breeds from evidence. The public course must not choose those breeds or publish a model pedigree answer.

## Safe website implementation

The course may include a neutral pedigree-reading guide that teaches diagram direction, parent-to-offspring links, the meaning of first-cross ewe and terminal sire, and evidence-based breed justification. The guide must:

- show only the source-authorised structural relationships;
- use neutral role labels for student-selected breeds;
- carry the Task 3 source ID and visible source boundary;
- provide useful alt text, caption and an `Open larger` link;
- avoid dimensions, farm-layout claims, husbandry instructions or a completed student response.

This source-derived guide satisfies the confirmed pedigree-drawing learning need. It does not convert the absent project/farm/yard plan into `Complete`; that separate gap remains `Teacher to confirm` and must stay visible.
